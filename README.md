# Sensai Gastrobar — Website Concept

Website conceitual criado para o Sensai Gastrobar, um gastrobar de assinatura oriental com alta gastronomia asiática, drinks autorais e atmosfera refinada em Curitiba, Paraná.

Este projeto foi desenvolvido como uma proposta profissional para uma empresa real e potencial cliente. A ideia é demonstrar como um website próprio pode fortalecer a presença digital da casa, organizar informações importantes e transformar o tráfego vindo de redes sociais e Google Maps em reservas, visitas e contatos pelo WhatsApp.

## Sobre o Projeto

O Sensai Gastrobar possui uma proposta visual pensada para canais digitais como Instagram, Facebook e Google Maps. Este website foi criado para complementar esses canais com uma experiência mais completa, elegante e direta.

O site apresenta:

- a identidade da casa;
- a proposta de gastronomia oriental;
- categorias do cardápio;
- drinks autorais;
- informações de contato;
- localização;
- links para redes sociais;
- chamadas para reserva via WhatsApp.

O objetivo é que o visitante entenda rapidamente a experiência oferecida e consiga decidir com facilidade se quer reservar uma mesa, conhecer o cardápio ou abrir a localização no Google Maps.

## Objetivo

O objetivo deste projeto é apresentar uma solução realista de website para o Sensai Gastrobar.

A proposta busca resolver problemas comuns de negócios locais que dependem muito de redes sociais, como:

- informações espalhadas em posts, stories e perfis;
- dificuldade de apresentar a experiência completa da casa;
- falta de uma página dedicada ao cardápio;
- ausência de uma experiência digital própria;
- dependência exclusiva de Instagram, Facebook e Google Maps;
- necessidade de facilitar reservas e contatos pelo WhatsApp.

## Direção Visual

A interface foi construída com uma estética escura, sofisticada e sensorial, alinhada à proposta do Sensai Gastrobar.

A direção visual utiliza:

- fundo marrom escuro e preto quente;
- tons dourados como destaque;
- laranja queimado para chamadas importantes;
- tipografia serifada elegante;
- tipografia script para reforçar sofisticação;
- títulos grandes e editoriais;
- bordas finas;
- imagens imersivas do ambiente e da gastronomia;
- cards escuros;
- contraste alto;
- layout limpo e premium.

A intenção foi evitar um site genérico de restaurante e criar uma presença digital com personalidade, próxima da atmosfera refinada da casa.

## Páginas do Projeto

### Home

A página inicial apresenta o Sensai Gastrobar de forma visual, direta e elegante.

Ela contém:

- hero com imagem da fachada;
- chamada principal;
- botão para reserva;
- atributos da marca;
- bloco sobre o ambiente;
- destaque para drinks autorais;
- destaque para sabores da casa;
- navegação para cardápio e reservas;
- footer com links úteis.

Chamada principal:

```text
Experiência
sensorial.
Noites refinadas.
```

### Cardápio

Página dedicada às categorias principais do cardápio.

Ela apresenta a experiência gastronômica da casa de forma limpa, visual e organizada, sem excesso de informação.

A página inclui:

- chamada principal;
- categorias do cardápio;
- imagens de cada categoria;
- descrições curtas;
- CTA para reserva.

Categorias listadas:

- Sushi;
- Pratos Quentes;
- Drinks;
- Sobremesas.

Também há uma chamada final para incentivar o visitante a viver a experiência completa e reservar uma mesa.

### Reservas

Página dedicada às informações de contato, reserva e localização.

Ela contém:

- chamada principal "Sua mesa espera por você";
- botão para reservar via WhatsApp;
- card com WhatsApp;
- endereço;
- informações de experiência;
- link para Instagram;
- mapa incorporado;
- acesso ao Google Maps.

## Experiência do Usuário

O site foi pensado para visitantes que chegam por redes sociais, indicações ou Google Maps e precisam de respostas rápidas:

- Que tipo de experiência a casa oferece?
- Onde fica?
- Como faço reserva?
- Tem cardápio?
- Tem drinks?
- Como falo com a casa?
- Como acesso as redes sociais?

Por isso, as chamadas principais levam o usuário para ações simples:

- reservar mesa pelo WhatsApp;
- conhecer o cardápio;
- abrir o Google Maps;
- acessar Instagram e Facebook.

## Propósito do Projeto

Este projeto foi criado como uma peça de portfólio e como uma proposta comercial.

A intenção é apresentar ao Sensai Gastrobar uma possibilidade real de website, mostrando como a empresa poderia ter uma presença digital mais organizada, profissional e própria.

O site demonstra como eu poderia ajudar o negócio a:

- fortalecer sua identidade online;
- organizar informações importantes;
- apresentar melhor a experiência da casa;
- apresentar o cardápio de forma visual;
- facilitar reservas pelo WhatsApp;
- melhorar a experiência de novos clientes;
- aproveitar melhor o tráfego vindo do Instagram, Facebook e Google Maps.

## Valor Potencial para o Sensai Gastrobar

Um website próprio pode ajudar a casa a:

- reduzir dúvidas frequentes dos clientes;
- centralizar localização, cardápio, reservas e contato;
- aumentar reservas pelo WhatsApp;
- melhorar a percepção profissional da marca;
- destacar a gastronomia oriental;
- apresentar melhor drinks, pratos e sobremesas;
- criar uma experiência digital mais consistente;
- depender menos exclusivamente das redes sociais.

## Aviso

Este é um projeto conceitual independente, criado para fins de apresentação profissional.

O projeto ainda não é o site oficial do Sensai Gastrobar.
As informações utilizadas combinam referências visuais, dados fictícios e conteúdo de apresentação do conceito.

Este projeto não é afiliado, aprovado ou oficialmente contratado pelo Sensai Gastrobar, a menos que uma futura aprovação ou parceria seja estabelecida.
